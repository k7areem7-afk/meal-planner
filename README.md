# سفرة 🍽️

مخطط وجبات أسبوعي بالعربي لأندرويد: تختار المتجر والميزانية، ويطلع لك أسبوع وجبات كامل مع قائمة مشتريات مسعّرة ومرتبة حسب أقسام المتجر.

## التثبيت على الجوال

1. افتح صفحة **Releases** في هذا المستودع من جوالك (وأنت مسجّل دخول في GitHub).
2. نزّل آخر ملف `sufra-XX.apk`.
3. افتحه واسمح بالتثبيت من مصادر غير معروفة إذا طلب الجوال.

كل نسخة جديدة تتثبت فوق القديمة وتبقى بياناتك.

## المرحلة الأولى (هذه النسخة)

- إعداد أولي: المتجر، عدد الأشخاص، الوجبات، النظام الغذائي، المطابخ، الحساسية، اللي ما تحبه، أجهزة المطبخ، الميزانية
- محرّك يبني خطة أسبوعية تحت الميزانية (حسب سعر العبوات الكاملة، مثل الكاشير)
- استبدال وجبة بمقارنة الفرق في التكلفة، وقفل وجبة، وإضافة وحذف
- 75 وصفة عربية أصلية، الكميات والخطوات تتغير مع عدد الحصص
- وضع الطبخ خطوة بخطوة مع مؤقت
- قائمة مشتريات حسب الأقسام: دمج المكرر، عدد العبوات، تأشير، "موجود عندي"، عناصر يدوية، نسخ للواتساب
- محرّر أسعار بالريال لكل متجر

## البنية

| المسار | المحتوى |
| --- | --- |
| `lib/` | كود Flutter |
| `tools/` | المكونات والأسعار والوصفات (Python) و`build_data.py` اللي يولّد `assets/data/*.json` |
| `docs/` | خريطة الاستطلاع ومصفوفة الميزات |
| `ci/debug.keystore` | مفتاح توقيع ثابت للاستخدام الشخصي |

لتعديل الوصفات أو الأسعار الافتراضية: عدّل `tools/recipes.py` أو `tools/ingredients.py` ثم شغّل `python3 tools/build_data.py`.

البناء يتم تلقائياً عبر GitHub Actions مع كل رفع إلى `main`.
