## 1. النطاق

| البند | القرار |
| --- | --- |
| التطبيق الأصلي | NeatEat – Meal Planner (Streamline Merch LLC)، صدر 17 يوليو 2026 |
| منصة النسخة | أندرويد |
| اللغة | عربي أولاً (RTL) |
| الشريحة | **كل الميزات** مثل الأصلي (اختيار المستخدم) |
| الجمهور | استخدام شخصي/عائلي، بدون اشتراكات وبدون نشر تجاري |
| الأسعار | أسعار تقديرية بالريال يعدّلها المستخدم بنفسه |
| المتاجر | متاجر سعودية (بنده، الدانوب، التميمي، العثيم، كارفور، لولو...) بدلاً من Walmart/Kroger/Aldi |

**الحلقة الأساسية (core loop):** أختار المتجر والميزانية ← يطلع لي أسبوع وجبات ← قائمة مشتريات مسعّرة ومجمّعة حسب الأقسام ← أطبخ.

**ملاحظة مهمة:** موقع NeatEat الرسمي يقول إن التطبيق متوفر على iPhone وأندرويد، ومتجر Google Play فيه "NeatEat: Meal & Recipe Planner" من مطوّر جديد اسمه Neat Builds (أقل من 1000 تحميل وقت البحث، ولم أتحقق إن كان نفس الشركة). ميزة نسختك: العربي، والريال، والمتاجر السعودية، والطبخ المحلي، وبدون اشتراك.

**أصعب الأجزاء:**
1. **محرّك الخطة المقيّد بالميزانية:** يختار وصفات تحقق الميزانية والحساسية والأجهزة والتنوع والماكروز معاً، ويحسب الكميات مع تحويل الوحدات ودمج المكرر. المراجعات تشتكي من التقدير الخاطئ للتكلفة ومن خطة تتغير بعد الشراء، وهنا فرصتك تتفوق على الأصلي.
2. **مكتبة الوصفات العربية:** مئات الوصفات بمكونات منظّمة، وكميات، وتغذية، وأسعار مربوطة بقاعدة المكونات. هذا محتوى وليس كوداً، وهو أكبر وقت في المشروع.
3. **ميزات الذكاء الاصطناعي:** مسح الثلاجة (رؤية حاسوبية)، واستيراد الوصفات من رابط أو سوشال أو صورة صفحة (تحليل نص إلى بيانات منظّمة). تحتاج API نموذج لغوي له تكلفة لكل استخدام.
4. (إضافي) مزامنة مشاركة الأسرة: باك إند وحسابات وتعارضات.

**التقدير: L (حوالي ربع سنة لمطوّر واحد)** للنطاق الكامل.
إذا بدأت بالحلقة الأساسية (S01–S11، S14–S18، S31، S34، بدون ذكاء اصطناعي وبدون مشاركة) يصير **M (عدة أسابيع)**، وبعدها تضيف الباقي على مراحل. وبما أنه استخدام شخصي، تقدر تبدأ بدون باك إند (تخزين محلي) وتضيف المزامنة لما توصل لمشاركة الأسرة.
